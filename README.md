## Лабораторная работа 10 — указатели, массивы и ссылки

## Задание 1

**Первый фрагмент:**

После `p = q` указатель `p` начинает хранить тот же адрес, что и `q`. Оба указывают на `b`, поэтому программа выведет:

```
20 20
```

**Второй фрагмент:**

Здесь адреса указателей не меняются. Значение объекта, на который указывает `p`, заменяется значением объекта, на который указывает `q`. То есть в `a` записывается `20`. Результат:

```
20 20
```

На первый взгляд вывод одинаковый, поэтому для демонстрации разницы нужно вывести также сами указатели и адреса переменных:

<img width="350" height="164" alt="Screenshot 2026-11-17 at 22 46 27" src="https://github.com/user-attachments/assets/a972ac0b-505b-47cb-9bbd-1e614efca207" />

**Итог:** `p = q` копирует адрес, а `*p = *q` копирует значение объекта.

## Задание 2

Чтобы получить десятичные значения, адрес нужно преобразовать в целочисленный тип — `std::uintptr_t`.

<img width="323" height="174" alt="Screenshot 2026-11-17 at 22 52 18" src="https://github.com/user-attachments/assets/16690c47-6887-47f0-a43f-c46896897cbd" />

Элементы массива расположены последовательно. Поэтому адрес каждого следующего элемента больше адреса предыдущего на размер одного `double`. На обычных платформах `sizeof(double)` равен 8 байтам, и получается арифметическая прогрессия с шагом 8.
