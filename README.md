## Задание 1

**Первый фрагмент:**

После `p = q` указатель `p` начинает хранить тот же адрес, что и `q`. Оба указывают на `b`, поэтому программа выведет:

```
20 20
```

**Второй фрагмент:**

Здесь адреса указателей не меняются. Значение объекта, на который указывает `p`, заменяется значением объекта, на который указывает `q`. То есть в `a` записывается `20`. Результат:

```
20 20
```

На первый взгляд вывод одинаковый, поэтому для демонстрации разницы нужно вывести также сами указатели и адреса переменных:

**Итог:** `p = q` копирует адрес, а `*p = *q` копирует значение объекта.

## Задание 2

Чтобы получить десятичные значения, адрес нужно преобразовать в целочисленный тип — `std::uintptr_t`.

## Задание 3

Токен `*` применяется в трёх контекстах:

1. В объявлении указателя — `int *p`.
2. При разыменовании указателя — `*p`.
3. Как оператор умножения — `a * b`.

Токен `&` также можно использовать тремя способами:

1. Как оператор взятия адреса — `&a`.
2. В объявлении ссылки — `int &r`.
3. Как побитовый оператор И — `a & b`.

```cpp
#include <iostream>

int main() {
    int a = 6;
    int b = 3;

    int *p = &a;       // * — объявление указателя, & — получение адреса
    int &r = a;        // & — объявление ссылки

    std::cout << *p << '\n';  // * — разыменование
    std::cout << a * b << '\n'; // * — умножение
    std::cout << (a & b) << '\n'; // & — побитовое И

    r = 10;
    std::cout << a << '\n'; // ссылка r — другое имя переменной a

    return 0;
}
```
